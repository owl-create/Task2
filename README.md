# 图片信息查看与简单编辑工具

一个用 Python 写的小工具:读取图片的基础信息,并对图片做**缩放、裁剪、旋转、翻转、灰度化、格式转换**。

程序是**命令行交互式**的:运行后会显示一个菜单,输入数字选择功能,按提示填写参数即可,不需要记复杂的命令行参数,也不需要安装界面库。

```
====================================================
       图片信息查看与简单编辑工具
====================================================

  1. 查看图片信息
  2. 缩放
  3. 裁剪
  4. 旋转
  5. 翻转
  6. 灰度化
  7. 格式转换
  q. 退出程序
请输入编号:
```

---

## 1. 功能清单

| 功能 | 说明 |
| --- | --- |
| 查看图片信息 | 显示文件名、图片格式、宽度和高度(像素)、颜色模式、文件大小(KB/MB,保留 2 位小数) |
| 缩放 | 指定宽高;只填宽或只填高时,另一边按原比例自动计算 |
| 裁剪 | 输入左、上、右、下四个坐标圈出区域;区域越界或坐标不合理时给出提示 |
| 旋转 | 顺时针 90 / 180 / 270 度 |
| 翻转 | 水平翻转(左右对调)、垂直翻转(上下对调) |
| 灰度化 | 彩色图转成灰度图 |
| 格式转换 | 例如 PNG 与 JPG 互转,还支持 BMP / WEBP / GIF / TIFF |

另外还有几条所有功能都遵守的规则:

- **不覆盖原图**:编辑结果一律另存为新文件,并打印出保存的完整路径
- **出错不闪退**:文件不存在、不是图片、参数不合法时,打印一句中文提示,程序继续运行
- **透明通道处理**:带透明通道的 PNG 存成 JPG 时,先铺一层白底再转成 RGB,透明区域不会变成黑块

## 2. 环境准备

### 2.1 需要 Python 3.8 或以上

在终端里输入下面的命令,能看到版本号即可(建议 3.10 以上):

```bash
python --version
```

如果提示"不是内部或外部命令",说明 Python 没装好,或者没有加入环境变量。到 <https://www.python.org/downloads/> 下载安装,安装时**勾选 "Add python.exe to PATH"**。

> macOS / Linux 上如果 `python` 命令不存在,把下文的 `python` 换成 `python3`。

### 2.2 安装依赖

本程序只依赖 **Pillow**(一个很好用的图片处理库),执行:

```bash
pip install -r requirements.txt
```

如果下载很慢,加上国内镜像:

```bash
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

也可以不用 requirements.txt,直接装:

```bash
pip install pillow
```

> 作业里推荐 OpenCV,本项目用的是 Pillow。原因见文末「常见问题」第 1 条——Pillow 安装更简单、对新手更友好,本次要求的全部功能都能完成。

## 3. 运行方法

### 3.1 先进入项目文件夹

**Windows**:用文件资源管理器打开项目文件夹,在空白处**按住 Shift + 鼠标右键**,选择"在此处打开 PowerShell 窗口"(或"在终端中打开")。

**macOS**:右键项目文件夹 → 服务 → 新建位于文件夹位置的终端窗口。

### 3.2 启动程序

```bash
python imgtool.py
```

看到菜单就说明成功了,输入 `1`~`7` 选择功能,输入 `q` 退出。

> 路径可以偷懒:直接把图片文件**拖进终端窗口**,路径会自动填进去;如果路径带空格和引号也没关系,程序会自动去掉引号。

## 4. 每个功能怎么用

下面的示例输出都是在 `samples/` 目录里的示例图片上跑出来的,你的文件大小可能与示例略有不同。

### 4.1 查看图片信息(菜单 1)

```
请输入编号:1
请输入图片路径(可以把文件直接拖到窗口里):samples\demo.jpg

  文件名     : demo.jpg
  图片格式   : JPEG
  宽度和高度 : 800 x 600 像素
  颜色模式   : RGB   (彩色图,红绿蓝三个通道)
  文件大小   : 31.91 KB
```

- 带透明通道的图片会显示 `RGBA   (彩色图 + 透明通道)`
- 黑白扫描件会显示 `L   (灰度图(黑白))`
- 文件大小按需求自动在 KB / MB 之间切换,统一保留 2 位小数

### 4.2 缩放(菜单 2)

**只填宽度**(高度按比例算):

```
请输入编号:2
请输入图片路径:samples\demo.jpg
  原图尺寸:800 x 600 像素
  宽和高只填一个也可以,另一边会按比例自动算。
目标宽度(像素,不填直接回车):400
目标高度(像素,不填直接回车):
  缩放后尺寸:400 x 300 像素

  保存到哪里?(直接回车 = samples\demo_resized.jpg):
  已保存:C:\Users\abc\image-tool\samples\demo_resized.jpg
  新图片尺寸:400 x 300 像素
```

- 只填高度也一样能算,`600` → `800x600` 的图会变成 `400x300`
- 宽高都填,就严格按你给的尺寸来(可能变形,这是预期行为)
- 直接回车则使用默认文件名 `原文件名_resized.后缀`

### 4.3 裁剪(菜单 3)

坐标从**左上角**开始算,左上角是 `(0, 0)`,横坐标向右、纵坐标向下:

```
    (0,0)
      +---------------------------------+
      |                                 |
      |      (left, top)                |
      |           +-----------+         |
      |           |  保留这块  |         |
      |           +-----------+         |
      |                 (right, bottom) |
      +---------------------------------+
```

示例:从 800x600 的图上裁出左上角 200x100 的一块:

```
请输入编号:3
请输入图片路径:samples\demo.jpg
  原图尺寸:800 x 600 像素
  坐标从左上角开始算,左上角是 (0, 0),右下角是 (宽, 高)。
  例如想保留中间 200x100 的一块,可以填 left=100 top=100 right=300 bottom=200
左边界 left:40
上边界 top:40
右边界 right:240
下边界 bottom:140
  裁剪后尺寸:200 x 100 像素
```

坐标给错时会明确提示,例如:

```
  -> 越界了:图片只有 800x600 像素,你给的是 left=40 top=40 right=9999 bottom=140。
     需要满足:0 <= left < right <= 800 且 0 <= top < bottom <= 600
```

### 4.4 旋转(菜单 4)

只支持 90 / 180 / 270 度,**顺时针**方向:

```
请输入编号:4
请输入图片路径:samples\demo.jpg
旋转角度(填 90、180 或 270,顺时针):90
  旋转后尺寸:600 x 800 像素
```

填其他角度会提示 `只支持 90、180、270 度(你填的是 45)`。

### 4.5 翻转(菜单 5)

```
请输入编号:5
请输入图片路径:samples\demo.jpg
  1 = 水平翻转(左右对调)
  2 = 垂直翻转(上下对调,像照镜子)
请选择:1
```

### 4.6 灰度化(菜单 6)

```
请输入编号:6
请输入图片路径:samples\demo.jpg
  已转成灰度图,颜色模式变成 L。
```

保存后再用菜单 1 看这张新图,颜色模式会显示 `L (灰度图(黑白))`。

### 4.7 格式转换(菜单 7)

```
请输入编号:7
请输入图片路径:samples\logo.png
  当前格式: PNG  颜色模式: RGBA
想转成什么格式?(填后缀,例如 jpg / png / bmp / webp):jpg
  已保存:C:\Users\abc\image-tool\samples\logo_converted.jpg
  新图片尺寸:400 x 300 像素
```

带透明通道的 PNG 转 JPG 时,透明的地方会铺成**白色**,不会出现黑色块。

## 5. 错误处理说明

程序里所有能想到的坑都做了提示,不会直接崩掉:

| 情况 | 程序反应 |
| --- | --- |
| 文件不存在 | `-> 找不到这个文件: xxx.jpg` |
| 路径是个文件夹 | `-> 这是一个文件夹,不是图片: ...` |
| 文件不是图片(或已损坏) | `-> 这个文件打不开,可能不是图片,或者文件已经损坏: ...` |
| 宽或高填 0 / 负数 | `-> 宽度必须大于 0(你填的是 0)。` |
| 宽高都不填 | `-> 宽度和高度至少填一个。` |
| 该填数字时填了汉字/字母 | `-> 这里要填数字,例如 400。请重新输入。`(然后重新问) |
| 裁剪区域越界或左右/上下反了 | 打印图片尺寸和要求,提示怎么改 |
| 旋转角度不是 90/180/270 | `-> 只支持 90、180、270 度(你填的是 45)。` |
| 输出路径和原图相同 | `-> 输出路径和原图一样。为了不覆盖原图,请换个文件名。` |
| 输出文件已存在 | 先问 `要覆盖它吗?(y/n)`,回答 n 就取消 |
| 输出后缀看不懂(如 `.xyz`) | 列出支持的扩展名 |

此外,万一出现完全预料之外的错误,程序只会打印一行提示并回到菜单,不会整个退出。

---

## 6. 不覆盖原图的规则

- 编辑结果一律写入**新文件**,原图一个字节都不会被改动
- 不给输出路径时,默认存成 `原文件名_功能名.后缀`(例如 `demo.jpg` → `demo_resized.jpg`),就在原图旁边
- 如果输出路径和原图**完全一样**,程序直接拒绝
- 如果目标文件**已经存在**,会先问一句再覆盖

## 7. 项目结构

```
image-tool/
├── imgtool.py          # 程序本体,所有功能都在这里
├── README.md           # 就是这份说明
├── requirements.txt    # 依赖清单(只有 Pillow)
├── .gitignore          # 忽略 __pycache__、虚拟环境、处理结果等
└── samples/            # 演示用的小图片
    ├── demo.jpg        # 800x600 彩色图
    ├── logo.png        # 400x300 带透明通道的图
    └── scan.png        # 300x200 灰度图
```

代码从上到下分成 4 块,每一块都写了注释:

| 部分 | 内容 |
| --- | --- |
| 第 1 部分 | 小工具函数:`ask_line` 读一行、`ask_number` 读整数、`size_text` 把字节转成 KB/MB、`mode_text` 翻译颜色模式、`make_output_path` 算默认输出名 |
| 第 2 部分 | 打开和保存:`open_image`、`save_image`、`put_on_white_background`、`finish`(保存统一入口) |
| 第 3 部分 | 七个功能函数:`feature_info`、`feature_resize`、`feature_crop`、`feature_rotate`、`feature_flip`、`feature_gray`、`feature_convert` |
| 第 4 部分 | `main()`:显示菜单、读用户选择、调用对应功能 |

## 8. 常见问题

**1. 为什么用 Pillow,而不是作业推荐的 OpenCV?**

作业的原文是"图片处理库**推荐** OpenCV",不是强制要求。本程序选 Pillow 的理由:

- 安装简单,`pip install pillow` 一条命令,不依赖 numpy 之外的编译库
- 代码更好读:图片宽高就是 `img.size`,颜色模式就是 `img.mode`,存成什么格式由 `img.save(路径, 格式)` 决定,不用处理 OpenCV 的 `BGR` 顺序、`None` 返回值那一套
- 读取颜色模式(需求要求显示 RGB / RGBA / 灰度)用 Pillow 更直接

所有功能要求都完整实现了。如果老师要求必须用 OpenCV,把 `open_image` / `save_image` 两个函数换掉即可,功能函数的调用方式不用改。

**2. 路径里有中文、空格,能用吗?**

可以。程序只是把路径原样交给 Pillow,Windows 下中文路径和空格都没问题。如果拖进终端后路径外面带了引号,`ask_line` 会自动去掉。

**3. 为什么存成 JPG 后透明背景变成了白色?**

JPG 格式本身没有透明通道。程序会自动把透明区域铺成白色再转 RGB(这是需求里"透明通道处理"那一条)。想要保留透明,请存成 PNG。

**4. 提示 `python 不是内部或外部命令`?**

Python 没装或者没加进 PATH。重新运行安装包,勾选 "Add python.exe to PATH";装完**重新打开**终端。

**5. 图片很大,处理很慢?**

程序的编辑是在内存里整张图操作的,几千万像素的大图会慢一点,属于正常现象。作业用的图一般不大,不影响。

**6. 处理结果存到哪里了?**

每次保存后都会打印一行 `已保存: 完整路径`。不看屏幕的话,结果就在原图所在的文件夹里,名字是 `原文件名_功能名.后缀`。
